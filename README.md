# 🎵 Spotify Web Player Clone

A fully responsive and interactive Spotify Web Player clone built from scratch using pure HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Features
- 🎶 **Dynamic Song Loading:** Fetches song lists and dynamically renders them into the UI.
- ⏯️ **Audio Player Controls:** Play, pause, previous, and next track functionality.
- 🎚️ **Interactive Seekbar:** Real-time song progress with custom seek functionality.
- 🔊 **Volume Control:** Adjust audio volume dynamically.
- 📱 **Responsive Design:** Hamburger menu for mobile/tablet sidebar navigation.
- 🎨 **Custom UI:** Custom dark-themed scrollbars, SVGs, and layout flexbox alignment.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Flexbox & CSS Variables)
- **Logic:** Vanilla JavaScript (ES6+, DOM Manipulation, Web Audio API)
